# CappAckiMiner

CappAckiMiner is a Windows desktop application for managing multiple authorized Acki Nacki wallets from one interface.

## Features

- Main and Lite multi-wallet views
- Isolated Main/Lite engines; only the active mode runs
- Wallet balance and recent reward tracking
- Balance-based wallet sorting
- CPU, temperature, TPS and network stress indicators
- QR wallet authorization and reconnection
- Shared license management across Main and Lite
- Encrypted wallet-profile transfer
- Turkish, English, Russian, Arabic, Simplified Chinese and Indonesian interface
- Local activity logs and automatic recovery controls

## Installation

Download the latest Windows installer from the [Releases](https://github.com/cappackiminer/cappackiminer/releases) page.

Portable packages are not distributed. Use the official installer.
